## Executive Overview

### What is TalentGrid?

TalentGrid is a comprehensive Human Resources Management System (HRMS) designed specifically for South African organizations. It serves as the **HR system of record**, consolidating data from existing Leave, CV/Skills, Projects/Timesheets, and Utilization applications through API integrations and scheduled CSV imports.

### Core Value Proposition

- **Single Source of Truth**: Centralized employee data repository
- **SA-Specific Compliance**: Built-in support for PAYE, ECSA, PDP, and SA labor legislation
- **Multi-Stakeholder**: Serves Admins, HR, Managers, and Employees with role-specific views
- **Data-Driven Decision Making**: Real-time analytics and reporting across all HR functions
- **Integration-First Design**: Designed to consume data from existing systems while maintaining sovereignty

### Key Statistics

- **9 Core Modules**: Dashboard, People, Compensation, Performance, Learning & Development, Leave, Projects/Timesheets & Utilization, HR Ops, Settings & Admin
- **4 User Roles**: Admin, HR, Manager, Employee
- **Full Accessibility**: WCAG AA compliant
- **Responsive Design**: Desktop, tablet, and mobile support
- **Multi-Theme**: Light and dark mode support

### 4. Performance Module (Version 2)

**Purpose**: Comprehensive performance appraisal management with multi-rater support

**Key Features**:

#### Appraisal Framework
- **Template-Based**: Uses standardized KPA structure (GENL-PER-03-01-01)
- **Balanced Scorecard**: 4 categories
  - **A) Internal Processes**: Work Methods, Ethics, Safety, Communication
  - **B) Financial**: Planning, Control
  - **C) Customer**: Knowledge, Quality, Volume, Stakeholder Engagement
  - **D) Learning & Growth**: Skills, Professional Development, Accountability

#### Multi-Rater Appraisal System
- **Minimum 2 Appraisers**: Employee (self) + Manager (primary)
- **Additional Assessors**: Supervisors who worked with appraisee on recent projects
- **Clear Appraisee Identification**: Every record shows who is being appraised
- **Appraiser Assignment**: Based on recent project collaboration

#### Hierarchical Flow
- **Top-Down Approach**: Managers must be appraised before appraising juniors
- **Sequence Tracking**: Each appraisal has a sequence number
- **Status Management**: Not Started → Self-Rating → In Review → Completed → Calibrated

#### Rating Scale
- **5.0**: Far Exceeds Expectations (Green)
- **4.0-4.5**: Exceeds Expectations (Green)
- **3.0-3.5**: Meets Expectations (Orange)
- **2.0-2.5**: Needs Improvement (Yellow)
- **1.0-1.5**: Major Improvement Required (Red)
- **N/A**: Not Applicable (Gray)

#### Appraisal Workflow
1. **Self-Rating**: Employee completes self-assessment
2. **Primary Assessment**: Manager rates employee
3. **Additional Input**: Supervisors provide input (in-person or electronic)
4. **Review Meeting**: Scheduled discussion of ratings
5. **Finalization**: Ratings locked and submitted
6. **Calibration**: HR-led calibration sessions

#### Calibration Features
- **Forced Distribution**: Manage rating distribution
- **Adjust Tool**: Modify ratings during calibration
- **Export Function**: Generate calibration reports
- **Consistency Check**: Ensure fair rating distribution

#### Analytics
- **Performance Distribution**: Pie chart of ratings
- **KPA Radar Chart**: Visual representation of competency areas
- **Trend Analysis**: Year-over-year performance trends
- **Department Comparison**: Performance by department

### Backend Data Store

#### Key-Value Store Structure

**Table**: `kv_store_052871c8`

**Functions** (`/supabase/functions/server/kv_store.tsx`):
- `get(key: string)`: Retrieve single value
- `set(key: string, value: any)`: Store single value
- `del(key: string)`: Delete single value
- `mget(keys: string[])`: Retrieve multiple values
- `mset(entries: [string, any][])`: Store multiple values
- `mdel(keys: string[])`: Delete multiple values
- `getByPrefix(prefix: string)`: Retrieve all keys with prefix

**Example Usage**:
```typescript
// Store employee data
await kv.set('employee:EMP001', employeeData);

// Retrieve employee data
const employee = await kv.get('employee:EMP001');

// Get all employees
const employees = await kv.getByPrefix('employee:');
```

## South African Compliance

### Tax Calculations

#### PAYE (Pay As You Earn)

**2024/2025 Tax Brackets**:
| Taxable Income (ZAR)    | Rate | Tax Calculation              |
|-------------------------|------|------------------------------|
| R0 - R237,100           | 18%  | Taxable income × 18%         |
| R237,101 - R370,500     | 26%  | R42,678 + (income - R237,100) × 26% |
| R370,501 - R512,800     | 31%  | R77,362 + (income - R370,500) × 31% |
| R512,801 - R673,000     | 36%  | R121,475 + (income - R512,800) × 36% |
| R673,001 - R857,900     | 39%  | R179,147 + (income - R673,000) × 39% |
| R857,901 - R1,817,000   | 41%  | R251,258 + (income - R857,900) × 41% |
| R1,817,001 and above    | 45%  | R644,489 + (income - R1,817,000) × 45% |

**Primary Rebate**: R17,235 (2024/2025)

#### UIF (Unemployment Insurance Fund)
- **Employee Contribution**: 1% of gross salary
- **Monthly Cap**: R177.12 (R2,125.44 annual)
- **Basis**: Income up to R17,712 per month

#### Net Pay Calculation
```typescript
Net Pay = Gross Salary - (PAYE - Primary Rebate) - UIF
```

**Implementation**: `/utils/currency.ts`

### Professional Registration

#### ECSA (Engineering Council of South Africa)
- **Registration Types**: Pr.Eng, Pr.Tech Eng, Pr.Cert Eng
- **CPD Requirement**: 30 hours per year (5 hours per category)
- **Salary Premium**: 10% for registered professionals
- **PDP Tracking**: Mentorship, evidence collection, monthly reports

#### SACPCMP (South African Council for Project and Construction Management Professions)
- **Registration Types**: Pr.CPM, Pr.CM, Pr.QS, Pr.Const
- **CPD Requirement**: 25-30 hours per year
- **Salary Premium**: 10% for registered professionals

### Labor Legislation References

#### LRA (Labour Relations Act, 1995)
- **Scope**: Employment contracts, termination, disciplinary procedures
- **Unfair Dismissal**: Substantive and procedural fairness
- **Maternity Leave**: 4 months

#### BCEA (Basic Conditions of Employment Act, 1997)
- **Working Hours**: 45 hours per week, 9 hours per day
- **Overtime**: 1.5× normal rate
- **Annual Leave**: 21 consecutive days per year
- **Sick Leave**: 30 days per 3-year cycle
- **Public Holidays**: 12 paid public holidays

#### EEA (Employment Equity Act, 1998)
- **Reporting**: Annual EEA reports (organizations with 50+ employees)
- **Demographics**: Race, gender, disability tracking
- **Affirmative Action**: Employment equity plans

#### POPIA (Protection of Personal Information Act, 2013)
- **Consent**: Employee consent for data processing
- **Data Minimization**: Collect only necessary data
- **Retention**: Retain only as long as necessary
- **Security**: Implement appropriate safeguards

#### SDA (Skills Development Act, 1998)
- **SDL**: 1% of payroll to Skills Development Levy
- **WSP/ATR**: Workplace Skills Plan and Annual Training Report
- **Learnerships**: Structured learning programs

- `GET /api/projects`: Fetch active projects
- `GET /api/timesheets`: Fetch timesheet data
- `GET /api/allocations`: Fetch resource allocations

**Sync Frequency**: Real-time (webhook-based)

---

#### 4. Utilization System Integration
**Type**: Calculated + API

**Calculation**:
```
Utilization % = (Billable Hours / Total Available Hours) × 100
```

**API Endpoints**:
- `GET /api/utilization/summary`: Monthly utilization summary
- `GET /api/utilization/employee/{id}`: Individual utilization

**Sync Frequency**: Daily at 6:00 AM

## Security & Permissions

### Role-Based Access Control (RBAC)

#### Admin Role
**Full Access**:
- All modules (read/write)
- Tenant settings configuration
- User role management
- System administration
- Audit logs

#### HR Role
**Module Access**:
- ✅ Dashboard (read)
- ✅ People (read/write)
- ✅ Compensation (read/write)
- ✅ Performance (read/write)
- ✅ Learning (read/write)
- ✅ Leave (read/write - all employees)
- ✅ Utilization (read)
- ✅ Policies (read/write)
- ❌ System Settings (read only)

#### Manager Role
**Module Access**:
- ✅ Dashboard (read - team metrics)
- ✅ People (read - team only)
- ✅ Compensation (read - team only, write - recommendations)
- ✅ Performance (read/write - team appraisals)
- ✅ Learning (read/write - team training requests)
- ✅ Leave (read/write - team leave approvals)
- ✅ Utilization (read - team utilization)
- ✅ Policies (read)
- ❌ System Settings (no access)

#### Employee Role
**Module Access**:
- ✅ Dashboard (read - personal metrics)
- ✅ People (read - public directory)
- ✅ Compensation (read - own data only)
- ✅ Performance (read/write - own appraisal)
- ✅ Learning (read/write - own training requests)
- ✅ Leave (read/write - own leave requests)
- ✅ Utilization (read - own utilization)
- ✅ Policies (read)
- ❌ System Settings (no access)

### Data Protection

#### Personal Information (POPIA Compliance)
- **Consent**: Explicit consent for data processing
- **Encryption**: Sensitive data encrypted at rest and in transit
- **Access Logs**: Audit trail of data access
- **Data Minimization**: Collect only necessary information
- **Right to Access**: Employees can request their data
- **Right to Deletion**: Employees can request data deletion (within legal limits)

#### Authentication & Authorization
- **Supabase Auth**: Email/password authentication
- **Social Login**: Google, GitHub (optional)
- **Session Management**: Token-based authentication
- **Password Policy**: Minimum 8 characters, complexity requirements
- **MFA** (Future): Multi-factor authentication


5. **Switch Roles**:
   Click on the profile avatar in the top right → Select role (Admin/HR/Manager/Employee)

### For Users

1. **Login** (Future implementation)
   - Navigate to login page
   - Enter credentials
   - Select role

2. **Navigate Modules**:
   - Use top navigation bar to switch between modules
   - Dashboard provides overview of all HR metrics

3. **Manage Employees**:
   - Go to People module
   - Click "Add Employee" to create new employee
   - Click "Edit" icon to update employee details
   - Use CSV import for bulk employee uploads

4. **Conduct Appraisals**:
   - Go to Performance module
   - Select appraisal cycle
   - Employees complete self-ratings
   - Managers complete primary assessments
   - Additional supervisors provide input
   - HR conducts calibration session

5. **Configure Settings**:
   - Click Settings icon (top right)
   - Or click profile avatar → Tenant Settings
   - Configure retirement age, date format, etc.

- **KPA**: Key Performance Area
- **LRA**: Labour Relations Act
- **PAYE**: Pay As You Earn (income tax)
- **PDP**: Professional Development Plan
- **POPIA**: Protection of Personal Information Act
