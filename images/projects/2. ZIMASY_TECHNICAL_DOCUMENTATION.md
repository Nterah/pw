# ZiMaSy - Zibambele Management System
## Technical Documentation & Architecture Overview

---

## 1. Executive Summary

**ZiMaSy** (Zibambele Management System) is a comprehensive web-based Progressive Web Application (PWA) designed for eThekwini Municipality to manage the Zibambele Programme - a government initiative providing part-time road maintenance work to beneficiaries in KwaMashu, Durban.

### Key Stakeholders
- **Primary Users**: 6 Employer Administrators
- **Secondary Users**: Operational Staff, Field Supervisors
- **Beneficiaries**: ~500 part-time workers (4-8 working days per month)

### Purpose
Centralized management of beneficiaries, attendance tracking, payments, safety incidents, tools/PPE distribution, and geographic information system (GIS) mapping for road maintenance segments.

**Business Rule Implementation:**
```typescript
// NOT full-time (22 working days/month)
// PART-TIME: 4-8 planned days per beneficiary per month

const calculateAttendanceStatus = (
  worked_days: number, 
  planned_days: number
): 'on_track' | 'behind' | 'at_risk' => {
  const percentage = (worked_days / planned_days) * 100;
  
  if (percentage >= 75) return 'on_track';      // Green
  if (percentage >= 50) return 'behind';        // Orange
  return 'at_risk';                             // Red
};
```
