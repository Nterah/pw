TalentGrid

South African HRMS • People Analytics • Compliance-Ready

Summary

TalentGrid is a production-ready design system and component library for recruitment apps. It standardizes profile cards, evaluation rubrics, pipeline stages, search filters, and analytics widgets so new features can be shipped faster and stay consistent. The system includes documentation, tokens (color/spacing/typography), accessibility guidelines, and responsive patterns for desktop and mobile.

  • Modular Figma kit mapped to React components
  • Candidate profile patterns (skills, projects, evidence)
  • Recruiter dashboards: pipeline health, funnel drop-offs

At a glance

Who it's for

  • HR teams needing one consolidated people dataset
  • Managers running approvals, appraisals, and team oversight
  • Executives who need headcount, utilisation, leave, and performance visibility

What it solves

  • Fragmented HR data spread across multiple tools and spreadsheets
  • Low-confidence reporting (multiple versions of “truth”)
  • Manual consolidation for board packs and management reporting
  • Inconsistent compliance evidence and process tracking

Problem

As organisations scale, HR information becomes scattered: leave is tracked in one place, skills/CVs in another, timesheets in another, and payroll exports are handled separately. This fragmentation increases admin time, increases reporting errors, and slows decision-making.

Solution

TalentGrid consolidates key HR information into a single system of record with analytics-first dashboards. The platform is structured as a modular HR suite so organisations can adopt it incrementally while still working toward a clean, unified data foundation.

Key workflows

  • Configure tenant settings, org structure, and master data rules
  • Import/sync people and HR data (CSV/API pipelines)
  • Run approvals and performance/appraisal workflows
  • Monitor dashboards (leave, utilisation, performance distribution)
  • Export clean reporting views for leadership and compliance packs

Notable features

  • Modular areas: Dashboard, People, Compensation, Performance, Learning & Development, Leave, Utilisation/Timesheets, HR Ops, Settings
  • Role-based UX: Admin / HR / Manager / Employee
  • Workforce analytics views for operational decision-making
  • Structured master data that supports reporting and governance
  • Designed for accessibility and responsive use across devices

Tech / Architecture

  • Frontend: React + TypeScript, Tailwind-based UI system
  • Backend: PostgreSQL-based storage + API layer (integration-ready)
  • Integrations: REST + scheduled import patterns for external systems

Challenges & decisions

  • Designing a “single source of truth” while supporting external systems of record
  • Balancing strict data structure with practical HR usability
  • Making analytics useful even when some sources are incomplete

Results / impact

  • Reduces manual HR reporting and spreadsheet consolidation
  • Improves confidence in people data and leadership reporting
  • Creates a scalable foundation for deeper HR automation and integrations
