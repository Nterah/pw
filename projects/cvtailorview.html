CVTailorView

Profiles • Projects • Advanced search • Word/PDF export

Summary

End-to-end CV management for engineering teams. Search by roles, skills, durations, and keywords; export polished CVs (template-based) with timelines and project summaries.

  • Global profile data model (skills, education, employment, affiliations)
  • Project filters: role fallback groups, value, date range, status, keywords
  • Template Word/PDF exports with charts/timelines
Visit Site

Architecture / Stack

PostgreSQL • Flask API • React UI • REST/JSON • Job queue for exports; image handling for headshots/signatures.
